# ระบบส่งอีเมลอัตโนมัติ + ส่งติดตามซ้ำ

เว็บ: https://project-email.vercel.app · รายละเอียดความต้องการ: [SPEC.md](SPEC.md)

## ระบบทำงานอย่างไร

```
cron-job.org (ทุก 1 นาที) ──► Vercel /api/cron/tick
                                ├─ 1) อ่านกล่องจดหมาย (IMAP): ใครส่งงานกลับ (ไฟล์แนบ/ลิงก์ Drive) / อีเมลไหนเด้งกลับ
                                ├─ 2) ส่งอีเมลที่ถึงเวลา (SMTP) ทีละไม่เกิน 10 ฉบับ
                                │     อีเมลส่งซ้ำ: ส่งเฉพาะเมื่อข้อ 1 สำเร็จ
                                └─ 3) วันละครั้ง: ลบไฟล์แนบ/รูปที่ค้าง (อัปโหลดแล้วไม่ได้ใช้เกิน 24 ชม.)
Supabase  ฐานข้อมูล + Storage (attachments = ไฟล์แนบ, email-images = รูปในเนื้อหา)
   ▲
หน้าเว็บ (ล็อกอินด้วย ADMIN_PASSWORD) — browser อัปโหลดไฟล์ตรงไป Supabase ไม่ผ่าน Vercel
```

## ใช้งาน

**ส่งอีเมลใหม่ (3 ขั้น):** ① เขียนอีเมล → ② ใส่ผู้รับ → ③ ตั้งเวลาส่ง แล้วกด "ยืนยัน"

- **แถบเครื่องมือแบบ Gmail:** แบบอักษร, ขนาด, ตัวหนา/เอียง/ขีดเส้นใต้/ขีดฆ่า, สีตัวอักษร/สีพื้นหลัง, จัดแนว, รายการ, เยื้อง (Tab/Shift+Tab), ข้อความอ้างอิง, ลิงก์, รูปภาพ, เส้นคั่น, ล้างรูปแบบ, เลิกทำ/ทำซ้ำ
- **{ชื่อ}:** กด "+ ใส่ชื่อผู้รับ" ระบบแทนด้วยชื่อแต่ละคนตอนส่ง
- **รูปภาพ:** กดปุ่มรูป / วาง (Ctrl+V) / ลากมาวาง · คลิกรูปแล้วกด "ขนาดรูป" เพื่อปรับ · ตอนส่งรูปถูกฝังในอีเมล (ผู้รับเห็นทันที) · ไม่เกิน 5 MB ต่อรูป
- **แนบไฟล์:** ปุ่ม "แนบไฟล์" ใต้เนื้อหา · รวมไม่เกิน 20 MB ต่ออีเมล · ไฟล์ที่ Gmail ห้าม (.exe ฯลฯ) จะถูกปฏิเสธ · ปกติแนบเฉพาะอีเมลแรก เลือก "แนบไฟล์ไปกับอีเมลส่งซ้ำด้วย" ได้ในขั้น ③
- **ตัวอย่างสด:** ด้านขวาของช่องเขียน (มือถือ: แท็บ "ดูตัวอย่าง") หน้าตาเหมือนที่ผู้รับเห็นใน Gmail รวมลายเซ็นและไฟล์แนบ
- **ลายเซ็นท้ายอีเมล:** ตั้งครั้งเดียวที่หน้า "ตั้งค่า" ต่อท้ายทุกอีเมลอัตโนมัติ (ใส่รูปโลโก้ได้)

**หน้ารายละเอียดข้อความ:** ตัวเลขสรุป (กดเพื่อกรอง) · ค้นหา · เมนู ⋯ ต่อคน (ส่งใหม่/หยุด/ลบ) · **⬇ Excel** ดาวน์โหลดรายชื่อกลุ่มที่กรองอยู่ (เช่น เฉพาะคนที่ยังไม่ส่งงาน) เปิดด้วย Excel ได้ ภาษาไทยไม่เพี้ยน

## งานดูแลที่อาจต้องทำ

| เรื่อง | ทำที่ไหน |
|---|---|
| เปลี่ยนเป็นอีเมลบริษัท (Google Workspace) | Vercel > Settings > Environment Variables: แก้ `GMAIL_USER`, `GMAIL_APP_PASSWORD` แล้ว Redeploy · หน้าเว็บ > ตั้งค่า: ขีดจำกัดต่อวันเป็น 1500 |
| เปลี่ยนรหัสผ่านเข้าเว็บ | Vercel: แก้ `ADMIN_PASSWORD` แล้ว Redeploy (ทุกเครื่องจะถูกออกจากระบบ) |
| App Password ถูกลบ / เปลี่ยนรหัส Google | สร้าง App Password ใหม่ แล้วแก้ `GMAIL_APP_PASSWORD` ใน Vercel + `.env.local` |
| หน้าแรกขึ้นแถบแดง "ระบบส่งอัตโนมัติไม่ได้ทำงาน" | ดู cron-job.org ว่างานยังเปิดอยู่และผลเป็น 200 |
| หน้าแรกขึ้นแถบแดง "ส่งอีเมลไม่ได้" / "ตรวจการส่งงานกลับไม่ได้" | ส่วนใหญ่เป็นเรื่อง App Password หรือ IMAP ถูกปิด |
| พื้นที่ Supabase (ฟรี 1 GB) | ไฟล์ของข้อความที่ลบแล้วถูกลบให้อัตโนมัติ · ถ้าใกล้เต็ม ลบข้อความเก่าที่มีไฟล์แนบ |

แก้โค้ดแล้ว `git push` — Vercel จะ deploy ใหม่ให้อัตโนมัติ

## ฐานข้อมูล

รันไฟล์ใน `supabase/migrations/` ตามลำดับ (001 → 006) ใน Supabase > SQL Editor (รันซ้ำได้)
ไฟล์ 006 (ลายเซ็น + แนบไฟล์ในอีเมลส่งซ้ำ): ถ้ายังไม่รัน ระบบใช้งานได้ปกติ แค่ 2 ฟีเจอร์นี้จะปิดอยู่

## คำสั่งบนเครื่อง (สำหรับพัฒนา/ทดสอบ)

```
npm run dev          เปิดเว็บทดสอบที่ http://localhost:3000
npm run cron:local   ตัวตั้งเวลาจำลองบนเครื่อง (ใช้คู่กับ dev)
npm run test:db      ทดสอบฐานข้อมูล
npm run test:gmail   ทดสอบล็อกอิน Gmail
node --env-file=.env.local scripts/e2e-ui.mjs        ทดสอบหน้าเว็บทั้งหมด + การส่งจริง (~6 นาที)
node --env-file=.env.local scripts/e2e-replies.mjs   ทดสอบตรวจส่งงานกลับ + ส่งซ้ำ (~6 นาที)
```

ทดสอบกับเว็บจริง (PowerShell): `$env:E2E_URL="https://project-email.vercel.app"` แล้วรันคำสั่ง e2e-ui ด้านบน
สคริปต์ทดสอบส่งอีเมลไปที่ `GMAIL_USER+…` (เข้ากล่องเดียวกัน) และลบข้อมูลทดสอบให้เองเมื่อจบ
